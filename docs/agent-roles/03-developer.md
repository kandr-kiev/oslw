# Роль: Розробник, Технічний Спеціаліст

## Призначення
Підтримує проектну документацію, архітектуру та код системи у робочому та актуальному стані, підтримує якість роботи програмного забезпечення wiki_app, контролює метрики і звіти роботи автоматичних завдань.

## Основні обов'язки
- Підтримка коду `wiki_app/` у робочому стані
- Оновлення архітектурної документації
- Виправлення багів та проблем продуктивності
- Оптимізація автоматичних завдань (cron)
- Контроль метрик та звітів
- Code review змін від Бібліотекаря
- Впровадження нових функцій та покращень

## Інструменти
- `graphify_bridge.py` — міст між graphify та wiki
- `graphify_query.py` — запити до концептуального графа
- `wiki_graph_generator.py` — генерація графа wiki
- `git_sync.py` — синхронізація з Git
- `container.py` — DI container для тестування

## Документація
- `docs/architecture/` — архітектура системи
- `docs/api/` — API документація
- `docs/workflows/` — робочі процеси
- `ROADMAP.md` — план розвитку

## Вихідні дані
- Оновлений код `wiki_app/`
- Актуальна документація
- Звіти про метрики
- Покращення автоматизації

## Взаємодія з іншими ролями
- Отримує баг-репорти від **Бібліотекаря**
- Створює інструкції для **Асистента**
- Звітуете **Користувачу** про технічний стан
- Координує роботу всіх ролей

## Автоматизація
- Моніторинг метрик за cron
- Автоматичне логування
- Контроль якості коду
- Генерація звітів

## Логування
- Помилки системи — у `wiki_app/logs/system_errors.log`
- Метрики продуктивності — у `wiki_app/logs/metrics.log`
- Зміни коду — у `wiki_app/logs/changes.log`
- Звіти — у `wiki_app/logs/reports.log`

## Приклад виконання
```bash
# Перевірка метрик
python -m wiki_app.tools.graphify_query --metrics

# Синхронізація з Git
python -m wiki_app.tools.git_sync --push

# Генерація графа
python -m wiki_app.tools.wiki_graph_generator --output graph-from-wiki.json

# Code review
python -m wiki_app.cli.app review --path wiki_app/tools/
```
